# Fundus Disease Classifier — Multi-Model Comparison

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/acorn-lab/fundus_disease_classifier/blob/main/notebooks/00_setup_colab.ipynb)

A reproducible benchmark that trains and compares **five image classifiers** on the
same fundus-photograph dataset, using one shared pipeline so the AUC/F1 numbers are
directly comparable. Built for BMEST580 (Biomedical AI).

> **Designed to run on Google Colab** (free GPU). Start with
> [`notebooks/00_setup_colab.ipynb`](notebooks/00_setup_colab.ipynb), which downloads
> the dataset and model weights and prepares everything in one pass — see
> [Quick start on Google Colab](#quick-start-on-google-colab) below.

The "ladder" of models, from a from-scratch baseline up to a foundation model:

| # | Model | What it is |
|---|-------|-----------|
| 1 | `cnn` | A vanilla CNN trained from scratch (lower-bound baseline) |
| 2 | `resnet50` | ImageNet-pretrained ResNet-50, fine-tuned |
| 3 | `vit` | `google/vit-base-patch16-224` |
| 4 | `dinov2` | DINOv2 self-supervised ViT backbone |
| 5 | `retfound` | RETFound MAE-pretrained ViT-L/16, a retinal foundation model |

All five share `fundus_lib/` for data, splits, preprocessing, training, and metrics,
so the only thing that changes between model notebooks is the backbone. Labels follow
the "bigclass" taxonomy (classes 0–9) from Cen et al. 2021.

## Repository structure


### Not in the repository (too large for GitHub)

These stay on your machine and are intentionally excluded by `.gitignore`. GitHub
rejects files over 100 MB, and these total several GB:

- `1000images/` — the raw fundus dataset (~858 MB)
- `cache_crops/` — preprocessed square crops (~137 MB), regenerated from the dataset
- `RETFound_cfp_weights.pth` — RETFound pretrained encoder (~3.7 GB)
- trained checkpoints and predictions (`*.pth`, `*.npz`) inside `results/`

To reproduce on a fresh clone, just run
[`notebooks/00_setup_colab.ipynb`](notebooks/00_setup_colab.ipynb): it downloads the
dataset and the RETFound weights and rebuilds `cache_crops/` and the manifest for
you (details under [Getting the data and the model weights](#getting-the-data-and-the-model-weights)).
Trained checkpoints are then regenerated by running the model notebooks.

## Quick start on Google Colab

This project is built to run on Colab with Google Drive for storage (the dataset
and the 3.7 GB RETFound weights are large, and Drive keeps them between sessions).

1. Open [`notebooks/00_setup_colab.ipynb`](notebooks/00_setup_colab.ipynb) in Colab
   (click the **Open in Colab** badge at the top, or in Colab choose
   *File → Open notebook → GitHub* and paste your repo URL).
2. **Runtime → Change runtime type → GPU.**
3. Run the cells top to bottom. The notebook will mount Drive, install
   dependencies, download the Kaggle dataset, download the RETFound weights, and
   build the cached crops.
4. Then run the model notebooks in order: `01_cnn` → `02_resnet50` → `03_vit` →
   `04_dinov2` → `05_retfound`, and finally `06_results`.

You only do the download steps once — on later sessions the data and weights are
already on your Drive.

## Getting the data and the model weights

These two downloads are automated inside `00_setup_colab.ipynb`, but here's what
they are and the credentials you need.

### Fundus dataset (Kaggle)

The images are the **"1000 Fundus images with 39 categories"** set (JSIEC,
Shantou; Cen et al. 2021):
<https://www.kaggle.com/datasets/linchundan/fundusimage1000>

You need a Kaggle API token: on kaggle.com go to **Account → Settings → API →
Create New Token**, which downloads `kaggle.json`. In Colab, add its two values as
**Secrets** (🔑 in the left sidebar) named `KAGGLE_USERNAME` and `KAGGLE_KEY`. The
setup notebook then downloads and unzips the dataset into `1000images/`. To do it
by hand:

```bash
pip install kaggle
# place kaggle.json at ~/.kaggle/kaggle.json (chmod 600), then:
kaggle datasets download -d linchundan/fundusimage1000 -p .
unzip -q fundusimage1000.zip -d 1000images
```

### RETFound weights (Hugging Face, gated)

RETFound's pretrained encoder is on a **gated** Hugging Face repo:
<https://huggingface.co/YukunZhou/RETFound_mae_natureCFP>

One-time access: (1) make a free Hugging Face account, (2) open that repo page and
click **Agree / request access**, (3) create a **read** token under
**Settings → Access Tokens**, (4) add it as a Colab secret named `HF_TOKEN`. The
setup notebook downloads the weight file and saves it as `RETFound_cfp_weights.pth`
(the name the notebooks expect). To do it by hand:

```python
from huggingface_hub import login, hf_hub_download, list_repo_files
import shutil
login(token="hf_...")                      # your read token
repo = "YukunZhou/RETFound_mae_natureCFP"
pth = [f for f in list_repo_files(repo) if f.endswith(".pth")][0]
shutil.copy(hf_hub_download(repo, pth), "RETFound_cfp_weights.pth")
```

## Setup (running locally instead of Colab)

Requires Python 3.10+ (a GPU is strongly recommended for the larger models).

```bash
python3 -m venv .venv
source .venv/bin/activate          # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Then launch the notebooks:

```bash
jupyter notebook
```

Run them in order: `00_preprocess_eda` first (builds the crops), then `01`–`05` to
train each model, then `06_results` to produce the comparison figures.

## Putting this on GitHub — baby steps

You only need to do steps 2–3 once. Your repo URL is already filled in below
username throughout.

### 1. Make sure git is installed

```bash
git --version
```

If that prints a version you're set. If not, install it (on macOS, running
`git --version` will offer to install the developer tools, or use `brew install git`).

### 2. Create an empty repository on GitHub

1. Go to <https://github.com/new>
2. **Repository name:** `fundus_disease_classifier` (or anything you like)
3. Choose **Private** (recommended while it's coursework) or Public
4. **Do NOT** check "Add a README", "Add .gitignore", or "Add a license" — this repo
   already has them, and adding them on the website would create a conflict
5. Click **Create repository**. Leave that page open; you'll need the URL it shows.

### 3. Connect this folder to that GitHub repo and push

This local folder is already a git repository with your first commit made.

First, a one-time cleanup: clear three empty `.lock` files left over from how the
repo was initialized (harmless, but they would block git until removed). From a
terminal **inside this folder**:

```bash
rm -f .git/HEAD.lock .git/index.lock .git/objects/maintenance.lock
```

Then connect to GitHub and push:

```bash
# point this repo at your new GitHub repo (use the URL from step 2)
git remote add origin https://github.com/acorn-lab/fundus_disease_classifier.git

# name the main branch and push it, setting it as the default upstream
git branch -M main
git push -u origin main
```

The first push will ask you to authenticate. The simplest path is to install the
[GitHub CLI](https://cli.github.com/) and run `gh auth login` once; afterwards
`git push` just works. (Alternatively, create a Personal Access Token under
GitHub → Settings → Developer settings and use it as your password when prompted.)

That's it — refresh your GitHub repo page and your code, notebooks, and README
will be there.

### 4. Day-to-day: saving future changes

After you edit code or notebooks, save them to GitHub with:

```bash
git add .
git commit -m "describe what you changed"
git push
```

To download a fresh copy somewhere else:

```bash

# 2. enter the folder
cd fundus_disease_classifier

# 3. create an environment and install dependencies
python3 -m venv .venv

pip install -r requirements.txt
```

Remember that the large data and weights are **not** in the repo (see
"Not in the repository" above) — add the dataset to `1000images/`, download the
RETFound weights, and run `00_preprocess_eda.ipynb` to rebuild the cached crops
before training.
